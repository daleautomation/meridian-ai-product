# prompts/

System prompts and agent instructions, separated from source code so they can
evolve independently and stay out of the indexer.

| Subdir   | Use                                            |
| -------- | ---------------------------------------------- |
| `claude` | Prompts for Claude (Code, API, Agent SDK)      |
| `cursor` | Cursor rules / agent context                   |
| `agents` | Multi-step / autonomous agent prompt suites    |
