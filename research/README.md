# research/

Long-form strategic / analytical writing that informs Meridian but is not
load-bearing for the running app. Excluded from semantic indexing.

| Subdir            | Use                                              |
| ----------------- | ------------------------------------------------ |
| `strategy`        | Strategic plans, GTM, positioning analysis       |
| `market-analysis` | Market research, competitive landscape           |
| `philosophy`      | Operating principles, theory-of-business essays  |
| `audits`          | Internal audits, refactor retrospectives         |

If a document explains *why* we build Meridian, put it here. If it explains
*how* the app works, put it in `docs/architecture/`.
